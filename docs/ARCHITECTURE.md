# AI采购风险控制系统架构说明

## 分层结构

```text
Vue 3 管理端 / 响应式业务端
          │ HTTPS / JSON
Spring Security → Controller → Service / Domain Rule → JPA Repository
          │                         │
      权限与审计              MySQL 8 / 外部适配器
```

- 表现层：模块导航、运营看板、台账、规则工作台、企业控制中心、审计和设置。
- 接口层：Bean Validation、统一响应、异常映射、角色权限和跨域控制。
- 领域层：采购申请、供应商画像、价格基准、关联关系、制裁筛查、单一来源、预算、审批与持续监测，以及专属决策评分和处置动作。
- 数据层：JPA 乐观锁、唯一业务编号、控制项幂等键和审计时间线。
- 集成层：仅定义 `SRM` 等外部系统引用和回执，不保存真实密钥。

## 部署边界

单机演示由 Docker Compose 启动 MySQL、后端和 Nginx 前端。正式生产应外置数据库与对象存储，接入企业 IAM、密钥管理、日志平台、监控告警、备份恢复和容灾设施，并完成容量压测、安全测试及业务 UAT。

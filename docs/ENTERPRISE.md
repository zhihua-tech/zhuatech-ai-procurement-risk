# AI采购风险控制系统企业能力

## 领域覆盖

- **采购申请**：维护需求、规格、数量、预算和期望交期
- **供应商风险画像**：综合资质、履约、财务、诉讼和负面事件
- **AI价格基准**：对比历史、市场、区域和规格形成价格区间
- **制裁与受益人**：筛查制裁名单、实际控制人和关联关系
- **单一来源治理**：记录必要性、替代方案、期限和例外审批
- **利益冲突**：执行采购人声明、关联方识别和回避
- **预算控制**：校验预算占用、超预算和承诺成本
- **风险审批**：按金额和风险执行多级审批与职责分离
- **持续监测**：跟踪供应商风险变化、交付和风险处置

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对AI采购风险控制系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `SRM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
